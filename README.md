## This project is a terminal python game in which you create, customize, and improve your own robot in order to increase it's chances of winning battles against other robots.

The player must first create the robot, and buy basic hardware/software (if possible) with the initial 300 credits recieved.
Winning battles against different robots give credits
Loosing gives nothing, and costs credits to repair your robot.

The more credits you get, the more hardware and software you can buy.

# Maximize your robot's potential to win as many battles as possible.
